==================================================
PROJECT CONCEPT
==================================================

The final system will work approximately like:

BME688
   ↓
ESP32
   ↓
Sensing Agent
   ↓
Forecasting Agent
   ↓
Fruit condition prediction
   ↓
Logistics Agent
   ↓
Negotiator Agent
   ↓
Store + vehicle + route
   ↓
Web Dashboard

Example:

Prediction:
"Batch F001 = RIPE
Confidence = 87%
Remaining shelf life = 3 days"

Logistics:
"High priority.
Recommended destination = Store B."

Negotiator:
"Vehicle 2 selected."

The dashboard should visualize this information.
