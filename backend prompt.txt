I am working on the BACKEND of a college major project.

The project is a multi-agent fruit monitoring and intelligent logistics system.

The hardware/sensing and ML prediction portions are being developed by another teammate, so DO NOT wait for the real ESP32 or trained model. Use MOCK DATA initially.

Your goal is to build the backend and the backend-side multi-agent system so that it can later connect to the real ESP32 and ML prediction system.

==================================================
PROJECT CONCEPT
==================================================

The system works like this:

BME688 + ESP32
      ↓
Sensing Agent
      ↓
Forecasting Agent
      ↓
Fruit condition prediction
      ↓
Logistics Agent
      ↓
Negotiator Agent
      ↓
Store + vehicle + route decision
      ↓
Web Dashboard

Example:

Forecasting Agent:
"Batch F001 is RIPE and has approximately 3 days remaining."

Logistics Agent:
"This batch should be dispatched with high priority and a suitable store should be selected."

Negotiator Agent:
"Vehicle 2 is the best available resource for this delivery."

Frontend:
Displays all of this on a dashboard and map.

==================================================
LOGISTICS AGENT
==================================================

The Logistics Agent should receive information such as:

- Fruit/batch ID
- Fruit condition
- Prediction confidence
- Remaining shelf life
- Store information
- Store distance
- Store capacity/demand
- Vehicle availability
- Delivery information

It should determine a suitable logistics action.

Do not simply implement "nearest store."

The decision can consider:
- Remaining shelf life
- Distance
- Store suitability
- Demand/capacity
- Delivery time
- Priority

For a college prototype, this can be implemented using a simple scoring/optimization approach rather than an extremely complicated algorithm.

Example:

Batch:
RIPE
3 days remaining

Available stores:
Store A — 2 km — low demand
Store B — 5 km — high demand
Store C — 8 km — medium demand

The Logistics Agent should be able to recommend a suitable store.

==================================================
NEGOTIATOR AGENT
==================================================

The project uses the concept of the Contract Net Protocol.

Implement a practical simplified version.

Example:

Logistics Agent creates a delivery task:

"Deliver Batch F001 to Store B."

Available vehicles:

Vehicle 1
- Available
- 10 km away

Vehicle 2
- Available
- 3 km away

Vehicle 3
- Busy

The Negotiator Agent can request/compare bids and select the best available resource.

The final result might be:

Vehicle 2 selected.

Make sure the implementation clearly demonstrates the concept of negotiation between agents.
